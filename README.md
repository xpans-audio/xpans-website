# xpans Website

The xpans website is built with [Astro](https://astro.build).

## Developing
You must have Node and pnpm installed.

Install dependencies using
```sh
pnpm install
```

### Running the dev server
The following command runs a local development server:
```sh
pnpm dev
```
This one makes it accessible from other devices on your network:
```sh
pnpm dev --host
```

### Building
The following command builds the site:
```sh
pnpm build
```

The result will be in the `dist/` folder.
